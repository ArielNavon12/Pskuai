# פרויקט אנדרואיד רשמי עבור פסוקאי (Google Play TWA)

פרויקט Android Studio מוכן ומלא ליצירת חבילת AAB / APK עבור Google Play Store.

## הוראות בנייה:
1. פתחו את התיקייה ב-Android Studio.
2. בחרו בתפריט: **Build > Generate Signed Bundle / APK**.
3. בחרו ב-**Android App Bundle (.aab)**.
4. קובץ ה-Keystore כבר מוטמע: `app/pasukai-release-key.jks`, סיסמה: `pasukai123`, alias: `pasukai`.
5. העלו את קובץ ה-`.aab` שנוצר ישירות לחשבון שלכם ב-Google Play Console!
